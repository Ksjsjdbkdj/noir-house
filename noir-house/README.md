# NOIR HOUSE — Multi-Page Café Website

A responsive four-page café website created for the Web Technology Assignment 1.

## Pages
- `index.html` — home page with hero section and featured items
- `menu.html` — menu displayed in an HTML table
- `gallery.html` — six-image gallery, lightbox and HTML5 video
- `contact.html` — reservation form and embedded Google Map

## Features
- Shared external CSS and JavaScript
- Semantic HTML5 structure (`header`, `nav`, `main`, `section`, `article`, `footer`)
- Responsive layout using CSS Grid, Flexbox and media queries
- Dark/light mode preference saved in `localStorage`
- Mobile hamburger navigation
- Gallery lightbox
- Form labels and built-in HTML validation
- Menu table with eight body rows and a `colspan`

## Run locally
Open `index.html` in a browser, or use the VS Code Live Server extension.

## Notes
This is a front-end academic demo. The reservation form displays a confirmation message in the browser; it does not send bookings to a real café. Images and the sample video load from external URLs, so an internet connection is needed for those assets.

## Deployment
Push the folder to a GitHub repository, then import the repository into Netlify or Vercel. No build command is required; publish the project root.
